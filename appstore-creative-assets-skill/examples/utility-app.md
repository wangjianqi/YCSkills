# Example: Utility App

## User input

```text
App name: ScanFlow

The app scans documents and produces clean PDFs.
The UI is light, compact, and highly functional.

Create a 3:2 Search Results asset.
```

## Expected direction

A transformation concept is likely stronger than a decorative concept:

```text
document → clean digital PDF
```

Use the actual app UI as evidence.

Keep the copy short and make the result recognizable at thumbnail size.

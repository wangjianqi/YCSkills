# Example: Creative App

## User input

```text
App name: MotionLab

The app uses dark charcoal backgrounds, a restrained orange accent,
large geometric controls, and a visual editor with timeline-based animation.

Create Search Results artwork.
```

## Expected direction

The Skill may amplify:

- dark visual language
- orange accent
- timeline / motion concept
- one strong editor state

It should not automatically add generic "AI" effects, particles, or unrelated 3D objects.

# Example: Minimal Utility App

## User input

```text
App name: FocusList

The app has a very minimal interface:
white background, black typography, thin dividers, compact list rows,
no illustrations, no gradients.

Create Product Page Header and Search Results assets.
```

## Expected direction

The Skill should not introduce:

- neon
- 3D objects
- colorful gradients
- decorative illustrations

A suitable direction would emphasize:

- FocusList
- one concise productivity benefit
- a clean crop of the real list UI
- generous white space
- typography consistent with the app

The marketing asset should feel like the app's own design system enlarged into a campaign.
